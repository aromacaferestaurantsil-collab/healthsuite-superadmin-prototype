# HealthSuite 360 — Super Admin prototype

Independent React/Vite project for Google AI Studio GitHub import.

- Synthetic demo data only.
- No Supabase connection, credentials, production data or external APIs.
- All changes are in-memory browser state only.
- No real authentication, authorization, billing, tenant suspension or deployment action is implemented.
- Super Admin must be enforced server-side with dedicated platform-level permissions before production integration.

Run: npm install && npm run dev
Build: npm run build

Import this repository into Google AI Studio Build mode. Keep it separate from the main dreamhealthsuite repository. After review, integrate approved code through a development branch and development backend only.
